# 第 0 章 · Hello, World!

> **卷一 · 语言**　|　前置知识：无　|　建议用时：20 分钟

每个 Python 教材都以同一个程序开始。不是因为它简单到没有东西可讲，而是因为它小到可以把每个字符都讲清楚。

这一章只做一件事：让程序向标准输出写下一行字，然后正常结束。但它已经包含了 Python 程序的全部骨架：一个模块、一个函数定义、一条表达式语句、一个模块级条件。

## 0.1 本章语法地图

| 语法 | 本章出现的位置 |
|------|----------------|
| 注释 | `# ...` |
| 文档字符串 | `"""..."""` |
| 函数定义 | `def main() -> None:` |
| 函数调用 | `print("Hello, World!")` |
| 字符串字面量 | `"Hello, World!"` |
| 表达式语句 | `print(...)` |
| 缩进块 | 函数体比 `def` 多缩进一级 |
| 模块级名字 | `__name__` |
| 条件语句 | `if __name__ == "__main__":` |

## 0.2 完整程序

```python
def main() -> None:
    print("Hello, World!")


if __name__ == "__main__":
    main()
```

仓库里的 [`hello.py`](hello.py) 是同一程序的注释版。可以先读这份没有注释的骨架，再打开注释版，看每个部分如何落在源码里。

## 0.3 运行

在本章目录 `00-hello-world/` 中执行：

```sh
python3 hello.py
```

你应该看到：

```text
Hello, World!
```

这条命令的每个部分都在说话：

| 片段 | 含义 |
|------|------|
| `python3` | Python 解释器。本书以 CPython 3.12 为基线。 |
| `hello.py` | 要执行的脚本文件。 |
| `python3 -W error hello.py` | 把警告变成错误，适合检查示例。 |
| `python3 -m compileall .` | 只做语法编译检查，不执行程序。 |

在仓库根目录也可以直接：

```sh
make run
```

或者先检查：

```sh
make check
```

编译成功只说明“语法和字节码生成”成功；运行成功才说明程序真的做了你想让它做的事。Python 没有链接步骤，但“能导入”和“能正确运行”仍然是两件事。

## 0.4 从源文件到执行

CPython 执行一个脚本，大致经过这条流水线：

```text
hello.py
   │  读取源码（默认 UTF-8）
   ▼
词法分析 / 语法分析
   │
   ▼
抽象语法树（AST）
   │  编译
   ▼
字节码（code object）
   │  缓存到 __pycache__/hello.cpython-312.pyc（可选）
   ▼
CPython 虚拟机逐条执行字节码
```

几个关键点：

- Python 通常**没有单独的链接阶段**。模块在导入时被找到、编译、执行。
- `.pyc` 是 CPython 的字节码缓存，不是跨版本可移植的目标文件；不同 Python 版本的 `.pyc` 不能混用。
- CPython 是解释器的一种实现；语言规范不要求一定用字节码或虚拟机。PyPy、GraalPy 等实现可能采用不同策略。
- Python 的“编译错误”通常叫 `SyntaxError`，在读取/编译阶段出现；“运行时错误”则是异常，例如 `NameError`、`TypeError`。

这条流水线解释了两种不同的错误：

- **语法错误**：解释器读不懂源码，例如少了冒号、括号不配对、缩进不一致。
- **运行时异常**：语法没问题，但执行到某条语句时失败，例如访问未定义的名字、除以零、类型不匹配。

后面我们会反复用到这个区分。现在只需要记住：**能编译，不等于能运行；能运行，不等于逻辑正确。**

## 0.5 逐行解剖

### 注释：写给人的空白

Python 只有一种注释：

```python
# 从 # 到本行末尾都是注释
value = 42  # 也可以写在语句后面
```

注释不是程序行为的一部分。解释器在词法分析阶段会忽略它。

三引号字符串不是注释：

```python
"""
这看起来像多行注释，
但它其实是一个字符串表达式。
"""
```

如果它出现在模块、函数或类的开头，就叫**文档字符串**（docstring），会被保存到 `__doc__` 里，供 `help()` 和文档工具使用。没有赋给任何名字的普通字符串表达式会被求值然后丢弃，所以常被当作“多行注释”使用，但语义上仍然是字符串。

好的注释解释“为什么”，而不是把代码翻译成自然语言。

### `def main() -> None:`：定义一个函数

```python
def main() -> None:
```

把它拆开：

| 片段 | 名称 | 含义 |
|------|------|------|
| `def` | 关键字 | 开始一个函数定义。 |
| `main` | 函数名 | 只是一个普通名字，不是语言规定的入口。 |
| `()` | 参数列表 | 这个函数不接受参数。 |
| `-> None` | 返回类型注解 | 表示这个函数返回 `None`；解释器不会强制检查。 |
| `:` | 冒号 | 函数头结束，下面是函数体。 |

关于 `main`，有几条现在就该建立的直觉：

- Python 没有“必须叫 main 的入口函数”。脚本从顶层的第一条语句开始执行。
- `main` 是约定，不是关键字。叫 `run`、`start` 也完全可以。
- 返回类型注解 `-> None` 是给人和静态检查工具看的；运行时不会因为返回了别的类型而报错。
- 函数体必须缩进。Python 用缩进表示代码块，不用 `{}`。

### 文档字符串

```python
def main() -> None:
    """
    程序的入口。
    """
```

函数体第一条语句如果是字符串字面量，它就是函数的文档字符串，保存在 `main.__doc__` 中。它不是必须的，但对公共函数很有用。

### `print("Hello, World!")`：一次函数调用

```python
print("Hello, World!")
```

这是一条**表达式语句**，由一次函数调用组成：

- `print` 是内置函数，不是关键字。
- `(...)` 是调用运算符，括号里是实参。
- `"Hello, World!"` 是字符串字面量。
- 这条语句没有赋值给任何名字；调用结果（`None`）被丢弃。

`print` 的默认行为：

- 把每个参数转换成字符串；
- 用空格分隔多个参数；
- 在末尾输出一个换行符；
- 返回 `None`。

```python
print("a", "b")          # a b
print("a", "b", sep="-") # a-b
print("a", end="")       # 不换行
print("b")
```

字符串字面量的类型是 `str`。Python 3 的 `str` 是 Unicode 码点序列，不是字节数组；编码问题第 6 章会讲。

`print` 不会自动给字符串加引号；如果你想看“可重建的表示”，用 `repr`：

```python
print("hello")        # hello
print(repr("hello"))  # 'hello'
```

### `if __name__ == "__main__":`：模块入口

```python
if __name__ == "__main__":
    main()
```

`__name__` 是解释器为每个模块设置的全局名字：

- 直接运行 `hello.py` 时，`__name__` 等于 `"__main__"`；
- 用 `import hello` 导入时，`__name__` 等于 `"hello"`。

所以这个条件的意思是：**只有直接运行这个文件时，才调用 `main`；被导入时只提供函数和类，不执行入口逻辑。**

这不是语言强制的入口机制，而是一个约定。它让同一个文件既能当脚本，又能当模块：

```sh
python3 hello.py          # 执行 main
python3 -c "import hello" # 不执行 main
```

`if` 语句、缩进、字符串比较，都是我们后面会展开的语法。现在只需要知道：Python 的“入口”是模块顶层的代码，`main()` 只是被这个条件调用而已。

## 0.6 缩进、标点与命名

Python 对缩进非常敏感：

- 同一个块里的语句必须有相同的缩进。
- 函数体、`if` 体、循环体都要比头部多缩进一级。
- 本书统一用 **4 个空格**。
- 不要混用 Tab 和空格；Python 3 会抛 `TabError`。
- 空行不影响语义，但影响可读性。

其他标点规则：

- 冒号 `:` 结束 `if`、`for`、`while`、`def`、`class`、`try` 等复合语句的头部。
- 逗号分隔参数、列表元素、字典项；行尾逗号是合法的，常用来减少 diff。
- 括号 `()`、`[]`、`{}` 决定表达式结构；括号内可以换行。
- 分号 `;` 可以分隔同一行的多条简单语句，但不推荐。
- Python 区分大小写：`print` 和 `Print` 不同，`main` 和 `Main` 不同。
- 只能用 ASCII 标点：中文的 `：`、`，`、`（）`、`“”` 不是 Python 的标点。

命名约定（PEP 8）：

| 对象 | 约定 | 例子 |
|------|------|------|
| 变量/函数 | `snake_case` | `user_name`、`parse_input` |
| 类 | `PascalCase` | `ExpressionParser` |
| 常量 | `UPPER_CASE` | `MAX_SIZE` |
| 私有/内部 | 前置下划线 | `_helper`、`__internal` |
| 特殊方法 | 双下划线 | `__init__`、`__repr__` |

约定不是语法，但违反约定会让读者误解你的意图。

## 0.7 故意改坏它

学习语法最快的方式之一，是故意违反它，然后读解释器的诊断。下面每个实验都建议真的做一遍。

| 改动 | 你大概会看到 | 它在说什么 |
|------|--------------|------------|
| 删掉 `def main() -> None:` 后的冒号 | `SyntaxError: expected ':'` | 复合语句头必须以冒号结束。 |
| 把函数体缩进改成 2 个空格 | 语法仍然合法，但风格不一致 | Python 只看相对缩进，不强制 4 空格。 |
| 混用 Tab 和空格 | `TabError: inconsistent use of tabs and spaces` | 缩进字符必须一致。 |
| 把 `print` 写成 `Print` | `NameError: name 'Print' is not defined` | Python 区分大小写。 |
| 删掉右括号 | `SyntaxError: '(' was never closed` | 括号必须配对。 |
| 把字符串引号改成中文引号 | `SyntaxError: invalid character '“'` | 中文标点不是 Python 标点。 |
| 把 `__name__` 写成 `__Name__` | `NameError: name '__Name__' is not defined` | 模块级名字区分大小写。 |
| 把 `main()` 调用删掉 | 程序什么也不输出 | 定义函数不会自动执行它。 |

读诊断时，先看**最后一行**的异常类型和消息，再看文件名、行号和插入符。Python 的 `SyntaxError` 会指出它认为出错的位置；有时真正的原因在上一行（例如少了右括号）。

运行时异常会打印**回溯**（traceback）：

```text
Traceback (most recent call last):
  File "hello.py", line 3, in <module>
    main()
  File "hello.py", line 2, in main
    print(message)
NameError: name 'message' is not defined
```

从下往上读：最后一行是错误类型和消息，上面是调用栈；最靠近底部的那一帧通常是最直接的错误位置。

## 0.8 语法卡片

| 术语 | 一句话定义 | 本章例子 |
|------|------------|----------|
| 模块 | 一个 `.py` 文件对应的执行单元 | `hello.py` |
| 函数定义 | 用 `def` 创建函数对象 | `def main(): ...` |
| 参数列表 | 函数名后括号里的参数 | `()` |
| 返回注解 | 给读者/类型检查器看的返回类型 | `-> None` |
| 文档字符串 | 函数/类/模块的第一条字符串 | `"""..."""` |
| 表达式语句 | 求出值后丢弃的表达式 | `print(...)` |
| 内置函数 | 解释器预定义、无需导入的函数 | `print` |
| 模块级名字 | 模块执行时创建的名字 | `__name__` |
| 入口条件 | 只在直接运行时执行代码的模式 | `if __name__ == "__main__":` |
| 缩进 | 用空格表示代码块 | 4 个空格 |

一个必须反复强调的区分：**`print` 不是 Python 语法的一部分，它是内置函数。** 本章真正属于语言的东西，是函数定义、函数调用表达式、字符串字面量、`if` 语句和缩进块。把“语言”与“标准库/内置函数”分开看，是这套教材的一条主线。

## 0.9 练习

1. **改名**：把 `Hello, World!` 换成你的名字，重新运行。只改字符串内容，不要动引号。
2. **两行**：用两个 `print` 输出两行；再改成一个 `print`，用 `\n` 完成。比较哪种写法更清楚。
3. **分隔符**：用 `print("a", "b", "c", sep="-")` 输出 `a-b-c`；再用 `end=""` 让两次 `print` 输出在同一行。
4. **入口**：在 `hello.py` 所在目录执行 `python3 -c "import hello"`，观察是否输出 `Hello, World!`。解释 `__name__` 的作用。
5. **退出码**：把 `main()` 调用改成 `raise SystemExit(7)`，在 shell 里用 `echo $?` 查看退出码。
6. **文档字符串**：给 `main` 加一个 docstring，运行 `python3 -c "import hello; print(hello.main.__doc__)"`。
7. **破坏实验**：删掉一个冒号、混用 Tab 和空格、把 `print` 写成 `Print`，分别记录异常类型和第一条诊断。
8. **回溯**：在 `main` 里故意写 `print(undefined_name)`，运行并从上到下读回溯，找出哪一行是真正的错误来源。
