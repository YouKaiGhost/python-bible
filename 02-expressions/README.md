# 第 2 章 · 表达式、运算符与求值

> **卷一 · 语言**　|　前置知识：第 1 章　|　建议用时：45 分钟

> 表达式不是数学公式的翻版。它规定了对象如何被组合、何时被求值、结果是新对象还是旧对象。

对象有了名字，接下来要让名字参与运算。这一章讲算术、比较、逻辑、位运算、真值、短路、海象运算符、解包和求值顺序。

Python 的运算符看起来和 C/C++ 很像，但有几个关键差异：`/` 总是浮点除法，`//` 是向下取整，`and`/`or` 返回操作数而不是布尔值，整数没有固定宽度，`is` 比较身份而不是值。

## 2.1 本章语法地图

| 语法 | 本章出现的位置 |
|------|----------------|
| 算术 | `+ - * / // % **` |
| 比较 | `< <= > >= == !=` |
| 成员关系 | `in`、`not in` |
| 身份 | `is`、`is not` |
| 逻辑 | `and`、`or`、`not` |
| 位运算 | `& \| ^ ~ << >>` |
| 赋值 | `=`、`+=`、`-=`、`*=` 等 |

| 条件表达式 | `a if condition else b` |
| 解包 | `a, b = ...`、`head, *tail = ...`、`**mapping` |

## 2.2 表达式与语句

**表达式**是能求出一个值的构造：

```python
1 + 2
"a" + "b"
x > 0
```

**语句**是执行一个动作的完整单位：

```python
x = 1 + 2
print(x)
if x > 0:
    ...
```

表达式可以作为语句单独出现，但结果会被丢弃：

```python
1 + 2      # 合法，但没有副作用
```

大多数有意义的表达式语句都带副作用：函数调用、赋值、`print`、修改容器。

## 2.3 算术运算

```python
a = 7
b = 3

a + b    # 10
a - b    # 4
a * b    # 21
a / b    # 2.3333333333333335
a // b   # 2
a % b    # 1
a ** b   # 343
```

### `/` 与 `//`

Python 的 `/` 是**真除法**，即使两个操作数都是整数，结果也是 `float`：

```python
7 / 2      # 3.5
7 // 2     # 3
```

`//` 是**向下取整除法**（floor division），不是“向零截断”：

```python
-7 // 3    # -3
-7 % 3     # 2
```

这与 C/C++ 的整数除法不同。C++ 的 `-7 / 3` 是 `-2`，Python 的 `-7 // 3` 是 `-3`。Python 的 `%` 结果符号跟随除数：

```python
7 % -3     # -2
-7 % 3     # 2
```

`divmod(a, b)` 同时返回商和余数：

```python
divmod(7, 3)     # (2, 1)
divmod(-7, 3)    # (-3, 2)
```

### 整数没有固定宽度

Python 的 `int` 是任意精度整数：

```python
2 ** 100
# 1267650600228229401496703205376
```

不会像 C/C++ 的 `int` 那样溢出。代价是大整数运算比机器字更慢，内存也更多。

需要固定宽度的整数（例如处理二进制协议）时，用 `int.to_bytes`、`int.from_bytes`，或者 `struct` / `array` 模块。

### 浮点是近似值

`float` 通常是 IEEE 754 双精度：

```python
0.1 + 0.2          # 0.30000000000000004
0.1 + 0.2 == 0.3   # False
```

需要比较时用 `math.isclose`：

```python
import math
math.isclose(0.1 + 0.2, 0.3)
```

需要精确十进制运算时，用 `decimal.Decimal`；需要精确分数时，用 `fractions.Fraction`。它们属于标准库，本章只提名字。

浮点还有 `inf`、`-inf` 和 `nan`：

```python
float("inf")
float("nan")
```

`nan != nan` 为真；判断 NaN 用 `math.isnan`。

### 幂与结合性

`**` 是右结合的：

```python
2 ** 3 ** 2   # 2 ** (3 ** 2) = 512
```

一元负号的优先级低于 `**`：

```python
-2 ** 2       # -(2 ** 2) = -4
(-2) ** 2     # 4
```

不确定时加括号。

## 2.4 真值

Python 的 `if`、`while`、`and`、`or`、`not` 都使用**真值测试**。以下值在布尔上下文中为假：

- `False`
- `None`
- 数值零：`0`、`0.0`、`0j`
- 空序列/容器：`""`、`[]`、`()`、`{}`、`set()`
- 空 `range(0)`

其他值通常为真：

```python
bool(0)        # False
bool(1)        # True
bool(-1)       # True
bool("")       # False
bool("0")      # True
bool([])       # False
bool([0])      # True
bool(None)     # False
```

注意 `"0"` 是真值，因为它不是空字符串；`[0]` 也是真值，因为它不是空列表。判断“有没有内容”与判断“内容是不是 0”是两件事。

自定义类可以通过 `__bool__` 或 `__len__` 定义真值，第 7 章会讲。

## 2.5 比较、成员关系与身份

```python
1 < 2          # True
2 <= 2         # True
1 == 1.0       # True
1 != 2         # True
3 in [1, 2, 3] # True
"a" in "cat"   # True
```

### 链式比较

Python 支持链式比较：

```python
1 < 2 < 3      # 等价于 1 < 2 and 2 < 3
1 < 2 > 3      # 等价于 1 < 2 and 2 > 3
```

中间的表达式只求值一次：

```python
1 < middle() < 10   # middle() 只调用一次
```

这在 C/C++ 里需要显式写两次。

### `==` 与 `is`

- `==` 比较值（调用 `__eq__`）；
- `is` 比较身份（是不是同一个对象）。

```python
first = [1, 2]
second = [1, 2]
third = first

first == second   # True
first is second   # False
first is third    # True
```

`is` 只应该用于单例或身份判断：

```python
if value is None:
    ...
```

不要用 `is` 比较数字或字符串的值。Python 3.8 起，`x is 1` 这类写法可能触发 `SyntaxWarning`。

### `in` 的复杂度

`in` 对列表是线性扫描，对字典/集合平均是 O(1)：

```python
3 in [1, 2, 3]          # O(n)
"a" in {"a": 1}         # O(1)
```

在循环里对列表做大量 `in` 判断，通常应该改用集合。

## 2.6 逻辑运算与短路

Python 的 `and`、`or` 不只是布尔运算符：它们**返回操作数本身**。

```python
0 or 42        # 42
42 or 0        # 42
0 and 42       # 0
42 and 0       # 0
"" or "default" # "default"
```

规则：

- `a and b`：先求值 `a`；如果 `a` 为假，返回 `a`，不执行 `b`；否则返回 `b`。
- `a or b`：先求值 `a`；如果 `a` 为真，返回 `a`，不执行 `b`；否则返回 `b`。
- `not a`：返回 `True` 或 `False`。

这带来常见惯用法：

```python
name = user_input or "anonymous"
```

如果 `user_input` 是空字符串，`name` 变成 `"anonymous"`。

但也要小心：如果合法的值可能是 `0` 或 `""`，`or` 会把它替换掉。需要区分“没有提供”和“提供了假值”时，用 `is None`。

### 短路

```python
if pointer is not None and pointer.value > 0:
    ...
```

如果 `pointer is None`，右侧不会求值，避免 `AttributeError`。短路是语言保证的顺序，不只是优化。

## 2.7 位运算

位运算作用于整数，按二进制位操作：

```python
x = 0x0F
y = 0x3C

x & y    # 0x0C
x | y    # 0x3F
x ^ y    # 0x33
~x       # -0x10
x << 2   # 0x3C
y >> 2   # 0x0F
```

Python 的整数没有固定位宽，因此：

- `~x` 等价于 `-x - 1`，结果可能是负数；
- 左移不会“溢出”，只会变大；
- 右移负数按算术右移处理（保持符号）；
- 没有无符号整数类型；需要无符号语义时用掩码，例如 `x & 0xFF`。

位运算常用于权限标志：

```python
READ = 1 << 0
WRITE = 1 << 1
EXEC = 1 << 2

permissions = READ | WRITE
can_read = bool(permissions & READ)
```

## 2.8 赋值、增强赋值与海象运算符

### 普通赋值

```python
x = 10
a = b = 0        # 链式赋值
x, y = 1, 2      # 元组解包
```

赋值语句先求值右侧，再把结果绑定到左侧目标。右侧只求值一次。

### 增强赋值

```python
x += 1
x -= 2
x *= 3
x /= 4
x //= 2
x %= 3
x **= 2
x <<= 1
x &= mask
```

对可变对象，增强赋值可能原地修改：

```python
values = [1]
alias = values
values += [2]
print(values, alias)   # [1, 2] [1, 2]
```

对不可变对象，增强赋值会创建新对象并重新绑定：

```python
text = "a"
alias = text
text += "b"
print(text, alias)     # ab a
```

这背后是 `__iadd__` 与 `__add__` 的区别，第 7 章会讲。

### 海象运算符

`:=`（3.8）在表达式内部绑定名字：

```python
if (size := len(data)) > 3:
    print(size)

while (value := next(iterator, None)) is not None:
    print(value)
```

它适合“先算一个值，再立即使用”的场景，避免重复计算或额外变量。不要为了少写一行而滥用；可读性优先。

## 2.9 条件表达式

```python
max_value = a if a > b else b
```

规则：

- 先求值条件；
- 条件为真选 `a`，为假选 `b`；
- 只有被选中的分支会被求值。

```python
value = 1 / 0 if flag else 0   # flag 为 False 时不会除零
```

条件表达式不是“三元运算符必须嵌套”的竞赛；复杂时用 `if` 语句。

## 2.10 解包

```python
first, second = [1, 2]
head, *tail = [1, 2, 3, 4]
*init, last = [1, 2, 3, 4]
```

`*` 收集剩余元素到列表。解包要求两边数量匹配（带星号时除外），否则抛 `ValueError`。

字典解包：

```python
defaults = {"a": 1, "b": 2}
merged = {**defaults, "b": 3, "c": 4}
```

列表/元组解包：

```python
combined = [*first, *second]
```

函数调用也可以解包：

```python
def f(a, b, c):
    ...

args = [1, 2, 3]
f(*args)

kwargs = {"a": 1, "b": 2, "c": 3}
f(**kwargs)
```

## 2.11 求值顺序

Python 通常从左到右求值：

```python
result = left() + right()   # left() 先于 right()
```

赋值语句先求值右侧：

```python
value = compute()           # compute() 先执行，再绑定 value
```

函数参数从左到右求值：

```python
f(first(), second(), third())
```

短路运算、条件表达式和 `and`/`or` 会跳过某些操作数，这是语义的一部分。

不要在表达式里依赖“未指定的顺序”。Python 的顺序比 C++ 更直观，但仍有例外：字典/集合的迭代顺序、`set` 的显示顺序、多线程交错等。

## 2.12 优先级

常见优先级从高到低：

```text
()  []  .                      # 分组、下标、属性
**                             # 幂（右结合）
+x  -x  ~x                     # 一元
*  /  //  %                    # 乘除
+  -                           # 加减
<<  >>                         # 移位
&                              # 位与
^                              # 位异或
|                              # 位或
==  !=  <  <=  >  >=  is  in   # 比较
not                            # 逻辑非
and                            # 逻辑与
or                             # 逻辑或
:=                             # 海象（优先级很低）
```

几个高频陷阱：

- `-2 ** 2` 是 `-(2 ** 2)`，不是 `(-2) ** 2`；
- `not a == b` 是 `not (a == b)`；
- `a or b and c` 是 `a or (b and c)`；
- `x = a if b else c` 整个条件表达式作为右侧；
- `lambda` 的优先级很低，复杂表达式要加括号。

不确定时加括号。括号不丢人，读错代码才丢人。

## 2.14 常见陷阱

| 写法 | 问题 | 建议 |
|------|------|------|
| `7 / 2` 期望整数 | `/` 返回浮点 | 用 `//` 做整数除法 |
| `-7 // 3` 期望 `-2` | Python 向下取整 | 明确需要哪种取整 |
| `0.1 + 0.2 == 0.3` | 浮点近似 | 用 `math.isclose` |
| `a is 1` | 身份不是值，且触发警告 | 用 `==` |
| `x = [] or default` | 空列表被当成“没有” | 需要区分时用 `is None` |
| `~x` 期望无符号结果 | Python 整数无固定宽度 | 用掩码 `x & 0xFF` |
| `values += [1]` 以为不影响别名 | 列表原地扩展 | 需要新列表时用 `values = values + [1]` |
| `*` 解包数量不匹配 | `ValueError` | 检查元素个数 |
| 在表达式里塞复杂逻辑 | 可读性差 | 拆成多条语句 |
| 依赖集合迭代顺序 | 不保证 | 需要顺序时排序或改用列表 |

## 2.15 语法卡片

| 术语 | 一句话定义 | 本章例子 |
|------|------------|----------|
| 真除法 | 结果总是浮点 | `7 / 2` |
| 向下取整除法 | 向负无穷取整 | `-7 // 3` |
| 取模 | 余数符号跟随除数 | `-7 % 3` |
| 真值测试 | 对象在布尔上下文中的真假 | `bool([])` |
| 短路 | 逻辑运算跳过不必要的操作数 | `p is not None and p.x` |
| 链式比较 | 多个比较共享中间值 | `1 < x < 10` |
| 身份 | 是否是同一个对象 | `a is b` |
| 海象运算符 | 表达式内绑定名字 | `(n := len(x))` |
| 解包 | 把序列拆成多个名字 | `a, b = pair` |
| 求值顺序 | 表达式各部分的执行顺序 | 从左到右 |

## 2.16 练习

1. **取整**：分别计算 `7 / 2`、`7 // 2`、`-7 // 2`、`7 % -3`、`-7 % 3`，总结规律。
2. **浮点**：验证 `0.1 + 0.2`、`math.isclose`、`1e308 * 10`、`float("nan")` 的行为。
3. **真值**：列出 10 个值，先猜它们的 `bool()`，再运行验证。
4. **短路**：写一个带打印的函数，放在 `and`/`or` 右侧，观察哪些调用没有发生。
5. **链式比较**：写一个只打印一次的 `middle()`，放进 `1 < middle() < 10`。
6. **海象**：用 `:=` 改写一个需要重复计算 `len(data)` 的 `if` 语句。
7. **解包**：用 `head, *middle, last` 拆分一个列表；再用 `*` 合并两个列表。
8. **位运算**：用 `1 << n` 定义权限位，实现 `has`、`add`、`remove` 三个函数。
9. **破坏实验**：把 `-7 // 3` 改成 `int(-7 / 3)`，比较结果并解释差异。
